# Nagbar releases

Downloads for [Nagbar](https://nagbar.app), the Mac app: reminders that take over your screen when it's time, and dictation in any app.

Each version is a release here, a notarized DMG for macOS 14 or later on Apple silicon. Installed copies update themselves through the signed feed at https://nagbar.app/appcast.xml.

The source code is private. Questions: hello@nagbar.app.
